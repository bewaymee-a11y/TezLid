# 🚀 Как запустить TezLid BYOB

## Быстрый старт (уже работает!)

У вас уже запущено:
- ✅ Frontend: http://localhost:3000
- ✅ Backend: http://localhost:8001

Теперь нужно подключить ngrok для тестирования webhooks.

---

## Шаг 1: Установите ngrok

**Windows:**
1. Скачайте: https://ngrok.com/download
2. Распакуйте в любую папку (например `C:\ngrok`)
3. Добавьте в PATH или запускайте из папки

---

## Шаг 2: Запустите ngrok

**Новый терминал:**
```powershell
# Если добавили в PATH:
ngrok http 8001

# Или напрямую из папки:
C:\ngrok\ngrok.exe http 8001
```

**Вы увидите:**
```
Forwarding  https://abc123.ngrok.io -> http://localhost:8001
```

**Скопируйте URL** (например: `https://abc123.ngrok.io`)

---

## Шаг 3: Обновите .env

```powershell
cd C:\Users\beway\.gemini\antigravity\scratch\TezLid-project\backend
notepad .env
```

**Добавьте строку:**
```
BASE_URL=https://abc123.ngrok.io
```

**Сохраните файл (Ctrl+S)**

---

## Шаг 4: Перезапустите backend

**В терминале где запущен backend:**
- Нажмите `Ctrl+C` для остановки
- Запустите заново:

```powershell
python -m uvicorn server:app --reload --port 8001
```

---

## Шаг 5: Создайте Telegram бота

**Telegram → @BotFather:**
```
/newbot
```

Следуйте инструкциям:
- Имя: `My TezLid Bot`
- Username: `mytezlid_bot` (должен быть уникальным)

**Получите токен:**
```
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

**Сохраните токен!**

---

## Шаг 6: Узнайте ваш Chat ID

**Telegram → @userinfobot:**

Отправьте любое сообщение, получите:
```
Id: 123456789
```

**Сохраните этот ID!**

---

## Шаг 7: Подключите бота через API

**Новый PowerShell терминал:**

```powershell
# Замените YOUR_BOT_TOKEN и YOUR_CHAT_ID на ваши значения!
$body = @{
    bot_token = "YOUR_BOT_TOKEN"
    manager_chat_id = YOUR_CHAT_ID
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:8001/api/companies?name=TestCompany" `
    -Method POST `
    -Body $body `
    -ContentType "application/json"
```

**Или через curl (если установлен):**

```bash
curl -X POST "http://localhost:8001/api/companies?name=TestCompany" \
  -H "Content-Type: application/json" \
  -d "{\"bot_token\": \"YOUR_BOT_TOKEN\", \"manager_chat_id\": YOUR_CHAT_ID}"
```

**Вы получите ответ:**
```json
{
  "success": true,
  "company_id": "abc-123-xyz",
  "bot_info": {
    "username": "mytezlid_bot",
    "first_name": "My TezLid Bot"
  },
  "webhook_url": "https://abc123.ngrok.io/telegram/webhook/abc-123-xyz/secret...",
  "message": "Bot @mytezlid_bot connected successfully"
}
```

## ⚠️ Troubleshooting

### Webhook не работает?

**1. Проверьте ngrok работает:**
- Откройте: http://127.0.0.1:4040
- Вкладка "Inspect" → должны видеть запросы от Telegram

**2. Проверьте BASE_URL:**
```powershell
cd backend
type .env | findstr BASE_URL
```
Должно совпадать с ngrok URL!

**3. Проверьте webhook установлен:**
```powershell
# Замените YOUR_BOT_TOKEN
$token = "YOUR_BOT_TOKEN"
Invoke-RestMethod -Uri "https://api.telegram.org/bot$token/getWebhookInfo"
```

Должно показать ваш webhook URL.

### Manager не получает сообщения?

1. **Отправьте `/start` вашему боту** (важно!)
2. Проверьте `manager_chat_id` правильный
3. Проверьте логи backend на ошибки

### Client не получает ответы?

1. **Отправьте `/start` вашему боту**
2. Проверьте логи backend

1. Проверьте все терминалы запущены:

   - ngrok
   - Frontend (опционально, port 3000)

2. Проверьте .env файл:
   - BASE_URL правильный
   - MongoDB работает
   - GOOGLE_API_KEY установлен

3. Проверьте логи backend и ngrok

4. Перезапустите backend после изменений в .env
