# 🤖 MVP Сервиса Автообработки Лидов через Telegram

Автоматическая система обработки входящих запросов от клиентов через Telegram с использованием AI для классификации лидов.

## 📋 Возможности

- ✅ Приём сообщений от клиентов через Telegram
- 🤖 AI-классификация лидов (горячий/тёплый/холодный)
- 📊 Определение услуги и срочности
- 💬 Автоматические ответы клиентам
- 🔔 Уведомления менеджеру о новых лидах
- 📈 Веб-интерфейс для просмотра лидов
- 🗄️ Сохранение всех лидов в базе данных

## 🚀 Быстрый старт

### 1. Создание Telegram бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "Мой Бизнес Бот")
   - Введите username бота (должен заканчиваться на `bot`, например: `my_business_leads_bot`)
4. Получите токен бота (выглядит как `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)
5. Сохраните этот токен!

### 2. Получение Chat ID менеджера

**Способ 1 - Через @userinfobot:**
1. Откройте [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте любое сообщение боту
3. Бот пришлёт ваш ID (например: `123456789`)
4. Это и есть ваш MANAGER_CHAT_ID

**Способ 2 - Через @getmyid_bot:**
1. Откройте [@getmyid_bot](https://t.me/getmyid_bot)
2. Нажмите "Start"
3. Получите ваш User ID

### 3. Настройка переменных окружения

Откройте файл `/app/backend/.env` и замените значения:

```bash
MONGO_URL="mongodb://localhost:27017"
DB_NAME="test_database"
CORS_ORIGINS="*"
EMERGENT_LLM_KEY=sk-emergent-79f643927CeD892C6A
TELEGRAM_BOT_TOKEN=ВАЫШ_ТОКЕН_БОТА_ЗДЕСЬ
MANAGER_CHAT_ID=ВАШ_CHAT_ID_ЗДЕСЬ
```

Замените:
- `TELEGRAM_BOT_TOKEN` - токен, полученный от @BotFather
- `MANAGER_CHAT_ID` - ваш Chat ID для получения уведомлений

### 4. Установка зависимостей

```bash
# Backend
cd /app/backend
pip install python-telegram-bot && pip freeze > requirements.txt

# Перезапуск сервера
sudo supervisorctl restart backend
```

### 5. Запуск Telegram бота

```bash
cd /app/backend
python bot_polling.py &
```

Бот начнёт слушать входящие сообщения!

### 6. Тестирование

1. Найдите вашего бота в Telegram по username
2. Нажмите "Start"
3. Отправьте сообщение, например:
   ```
   Здравствуйте! Хочу заказать ремонт квартиры. Нужно срочно!
   ```
4. Бот должен:
   - Ответить клиенту
   - Отправить уведомление менеджеру
   - Сохранить лид в базу данных
5. Откройте веб-интерфейс: http://localhost:3000
6. Увидите новый лид в панели!

## 🔧 API Endpoints

### Основные эндпоинты:

- `POST /api/telegram/webhook` - Приём сообщений от Telegram
- `GET /api/leads` - Получить все лиды (с фильтрами)
- `GET /api/leads/{lead_id}` - Получить конкретный лид
- `PUT /api/leads/{lead_id}/status` - Обновить статус лида
- `GET /api/stats` - Получить статистику лидов

### Примеры запросов:

```bash
# Получить все горячие лиды
curl http://localhost:8001/api/leads?lead_type=hot

# Получить срочные лиды
curl http://localhost:8001/api/leads?urgency=high

# Получить статистику
curl http://localhost:8001/api/stats
```

## 🤖 Как работает AI классификация

Система использует GPT-4 через Emergent LLM key для анализа каждого сообщения:

1. **Определение лида:**
   - `lead: true/false` - является ли сообщение потенциальным лидом

2. **Тип лида:**
   - 🔥 **hot** (горячий) - готов купить сейчас
   - ⚡ **warm** (тёплый) - интересуется, уточняет
   - ❄️ **cold** (холодный) - общий вопрос

3. **Срочность:**
   - 🔥 **high** - нужно срочно (сегодня/завтра)
   - ⚡ **medium** - в ближайшие дни
   - 📝 **low** - без спешки

4. **Услуга:**
   - Автоматически определяется из текста сообщения

5. **Генерация ответа:**
   - Вежливый и профессиональный ответ клиенту

## 🐛 Решение проблем

### Бот не отвечает на сообщения:

1. Проверьте, что `bot_polling.py` запущен:
   ```bash
   ps aux | grep bot_polling
   ```

2. Проверьте логи:
   ```bash
   tail -f /var/log/supervisor/backend.*.log
   ```

3. Убедитесь, что токен бота правильный в `.env`

### Менеджер не получает уведомления:

1. Проверьте `MANAGER_CHAT_ID` в `.env`
2. Убедитесь, что вы написали боту хотя бы раз (иначе бот не может вам писать)

### AI не классифицирует лиды:

1. Проверьте, что `EMERGENT_LLM_KEY` установлен
2. Проверьте баланс ключа (может закончиться кредит)
3. Посмотрите логи на наличие ошибок AI
